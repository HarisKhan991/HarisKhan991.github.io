## Key Visual Features

### 1. Navigation Bar
- **Desktop**: Full horizontal navigation with all links visible
- **Mobile**: Hamburger menu that expands to show all options
- **Sticky**: Stays at top when scrolling
- **Glassmorphism**: Semi-transparent with blur effect

### 2. Stats Cards
- **Gradient Overlays**: Subtle colored gradients behind each card
- **Icons**: Color-coded icons in rounded containers
- **Hover Effects**: Cards lift with shadow on hover
- **Responsive**: 4 columns on desktop, 2 on tablet, 1 on mobile

### 3. Quick Actions
- **Full Gradients**: Vibrant colored backgrounds
  - Blue-Cyan for Study Session
  - Purple-Pink for Add Subject
  - Green-Emerald for Analytics
  - Orange-Red for Feed
- **Large Icons**: 32px icons for easy recognition
- **Hover Animation**: Scales to 105% on hover
- **Text Contrast**: White text on colored backgrounds

### 4. Content Cards
- **Clean White Background**: With subtle shadows
- **Rounded Corners**: Modern aesthetic
- **Proper Spacing**: Breathing room between elements
- **Typography Hierarchy**: Clear visual hierarchy

### 5. Progress Bars
- **Color-Coded**: Different colors for different metrics
- **Smooth Animations**: Animated fill on load
- **Percentage Display**: Clear numerical indicators
- **Context**: Shows current/total values

### 6. Empty States
- **Helpful Icons**: Large, centered icons
- **Clear Messages**: Tells user what to do
- **Call-to-Action**: Button to get started
- **Friendly Tone**: Encouraging, not negative

## Color Palette

### Primary Colors
- **Blue**: #3B82F6 to #06B6D4 (Subjects, Primary actions)
- **Purple**: #A855F7 to #EC4899 (Analytics, Secondary actions)
- **Green**: #10B981 to #059669 (Progress, Success states)
- **Orange**: #F59E0B to #EF4444 (Scores, Warning states)

### Neutral Colors
- **Light Mode**:
  - Background: #F9FAFB, #FFFFFF, #F3F4F6
  - Text: #111827, #6B7280
  - Borders: #E5E7EB

- **Dark Mode**:
  - Background: #030712, #111827, #1F2937
  - Text: #F9FAFB, #9CA3AF
  - Borders: #374151

## Accessibility Features
- **High Contrast**: Text passes WCAG AA standards
- **Large Touch Targets**: 44px minimum for mobile
- **Keyboard Navigation**: Tab through all interactive elements
- **Screen Reader Support**: Semantic HTML and ARIA labels
- **Focus Indicators**: Clear visual feedback

## Performance
- **Lazy Loading**: Components load as needed
- **Memoization**: Prevents unnecessary re-renders
- **Optimized Images**: Responsive images with proper sizing
- **Fast Animations**: Hardware-accelerated transforms
- **Efficient Queries**: Data fetched only when needed

## Responsive Breakpoints
- **Mobile**: < 640px (sm)
- **Tablet**: 640px - 1024px (md, lg)
- **Desktop**: > 1024px (xl, 2xl)
- **Max Width**: 1280px (7xl) centered
